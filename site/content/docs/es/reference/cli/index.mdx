Ejecutá `vx --help` para esta lista, o `vx <command> -h` para un solo comando. Los nombres de los comandos, los flags, los ejemplos y lo que imprime el binario se muestran tal cual, en inglés. La explicación que los acompaña está en español, mientras que `vx <command> -h` la imprime en inglés.

| Comando | Descripción |
| --- | --- |
| [`vx init`](/es/docs/reference/cli/init) | Preparar el proyecto actual para que vexillum lo orqueste |
| [`vx upgrade`](/es/docs/reference/cli/upgrade) | Actualizar vx a la última release y después refrescar con ella el scaffold de vexillum del proyecto |
| [`vx doctor`](/es/docs/reference/cli/doctor) | Informar sobre la salud del entorno de vexillum |
| [`vx dispatch`](/es/docs/reference/cli/dispatch) | Despachar un soldier (mission o scout) a un camp aislado |
| [`vx models`](/es/docs/reference/cli/models) | Listar los perfiles de modelo y effort que puede usar un dispatch |
| [`vx yolo`](/es/docs/reference/cli/yolo) | Activar o desactivar el modo yolo para este proyecto, o imprimir si está activado |
| [`vx redispatch`](/es/docs/reference/cli/redispatch) | Volver a despachar una tarea interrumpida desde su prompt original |
| [`vx decide`](/es/docs/reference/cli/decide) | Responder la pregunta abierta de una tarea blocked para que pueda continuar |
| [`vx prompt`](/es/docs/reference/cli/prompt) | Enviar un prompt de seguimiento a un soldier que ya terminó |
| [`vx pending`](/es/docs/reference/cli/pending) | Registrar y limpiar las decisiones pendientes del propio commander |
| [`vx status`](/es/docs/reference/cli/status) | Informar sobre la tropa: cada mission y scout del proyecto actual |
| [`vx land`](/es/docs/reference/cli/land) | Aterrizar el trabajo de una mission terminada en la rama base de este proyecto |
| [`vx ship`](/es/docs/reference/cli/ship) | Hacer ship de una mission terminada por el pipeline de tribunal propio de vexillum, abriendo un pull request real |
| [`vx strike`](/es/docs/reference/cli/strike) | Hacer strike del camp de un soldier (desmontarlo y devolverlo al pool) una vez que su trabajo aterrizó |
| [`vx sentinel`](/es/docs/reference/cli/sentinel) | Vigilar a los soldiers despachados y registrar los cambios de status |
| [`vx forum`](/es/docs/reference/cli/forum) | Abrir un artefacto HTML local para revisión visual y recoger el feedback del usuario |
