# Referencias a los repositorios y/o proyectos 

## Referencia directa:

__firstmate__: la base conceptual entera. Coordinador único que despacha subagentes en paralelo, worktrees aislados, dos task shapes, supervisión zero-token, restart-proof. Todo tu modelo mental sale de acá. Es LA referencia. [Repositorio](https://github.com/kunchenguid/firstmate)
__treehouse__: relevante desde la Capa 3. Es el manejo de worktrees reutilizables aislados, o sea tu concepto de camp. Además está en Go, así que te sirve doble: como referencia conceptual y como ejemplo de código Go real haciendo exactamente la plomería de worktrees que vas a escribir. [Repositorio](https://github.com/kunchenguid/treehouse)

## Referencia lateral, no ahora:

__herdr__: la socket API que el sentinel consulta en Capa 4. Cuando llegues a la supervisión, su doc es referencia obligada. [Docs de Herdr](https://herdr.dev/docs/)
