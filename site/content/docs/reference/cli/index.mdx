| Command | Description |
| --- | --- |
| [`vexillum init`](/docs/reference/cli/init) | Prepare the current project to be orchestrated by vexillum |
| [`vexillum upgrade`](/docs/reference/cli/upgrade) | Refresh an already-initialized project's vexillum scaffold |
| [`vexillum doctor`](/docs/reference/cli/doctor) | Report on the health of the vexillum environment |
| [`vexillum dispatch`](/docs/reference/cli/dispatch) | Dispatch a soldier (mission or scout) into an isolated camp |
| [`vexillum redispatch`](/docs/reference/cli/redispatch) | Re-dispatch an interrupted task from its original prompt |
| [`vexillum decide`](/docs/reference/cli/decide) | Answer a blocked task's open question so it can continue |
| [`vexillum status`](/docs/reference/cli/status) | Report the current project's fleet of tasks |
| [`vexillum land`](/docs/reference/cli/land) | Land a finished mission's work into this project's base branch |
| [`vexillum ship`](/docs/reference/cli/ship) | Ship a finished mission through vexillum's own tribunal pipeline, opening a real pull request |
| [`vexillum release`](/docs/reference/cli/release) | Release a soldier's camp back to the pool once its work has landed |
| [`vexillum sentinel`](/docs/reference/cli/sentinel) | Watch dispatched soldiers and record status changes |
| [`vexillum forum`](/docs/reference/cli/forum) | Open a local HTML artifact for visual review and collect the user's feedback |
| [`vexillum banner`](/docs/reference/cli/banner) | Publish an HTML artifact to a public URL, or update one already published |
