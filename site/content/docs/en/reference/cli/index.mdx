| Command | Description |
| --- | --- |
| [`vx init`](/docs/reference/cli/init) | Prepare the current project to be orchestrated by vexillum |
| [`vx upgrade`](/docs/reference/cli/upgrade) | Refresh an already-initialized project's vexillum scaffold |
| [`vx doctor`](/docs/reference/cli/doctor) | Report on the health of the vexillum environment |
| [`vx dispatch`](/docs/reference/cli/dispatch) | Dispatch a soldier (mission or scout) into an isolated camp |

| [`vx status`](/docs/reference/cli/status) | Report the troop: every mission and scout in the current project |
| [`vx land`](/docs/reference/cli/land) | Land a finished mission's work into this project's base branch |
| [`vx ship`](/docs/reference/cli/ship) | Ship a finished mission through vexillum's own tribunal pipeline, opening a real pull request |
| [`vx release`](/docs/reference/cli/release) | Release a soldier's camp back to the pool once its work has landed |
| [`vx sentinel`](/docs/reference/cli/sentinel) | Watch dispatched soldiers and record status changes |
| [`vx forum`](/docs/reference/cli/forum) | Open a local HTML artifact for visual review and collect the user's feedback |
| [`vx banner`](/docs/reference/cli/banner) | Publish an HTML artifact to a public URL, or update one already published |
