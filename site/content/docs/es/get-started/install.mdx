title: Instalación
description: Instalá el binario de vexillum con Homebrew o el script de curl, elegí un canal de release y verificá tu entorno.
---

vexillum soporta macOS y Linux, en amd64 y arm64.

## Requisitos

- macOS o Linux, amd64 o arm64 (Windows no está soportado)
- [Claude Code](https://claude.com/claude-code), instalado y con sesión iniciada (suscripción o API key)
- [herdr](https://herdr.dev) (`brew install herdr` funciona)
- un repositorio git para tu proyecto
- opcional: `gh` (para `vx ship`) y `tmux`

`vx doctor` verifica todo esto. `vx dispatch` solo funciona dentro de un pane de herdr.

<Callout type="warn" title="Los soldiers tienen acceso total al host">
  Un soldier corre Claude Code con `--dangerously-skip-permissions`, con tu usuario del sistema, sin contenedor ni sandbox. Aterrizar una mission es la puerta de aprobación: nada llega al historial real de tu proyecto hasta que lo aprobás. Nunca despaches contra un repositorio o una máquina donde leer credenciales sería un problema.
</Callout>

## Instalá el binario

<CodeBlockTabs defaultValue="brew">
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="brew">brew</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="curl">curl</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="brew">
```bash
brew install isaias-alt/tap/vexillum
```
  </CodeBlockTab>
  <CodeBlockTab value="curl">
```bash
curl -fsSL https://raw.githubusercontent.com/isaias-alt/vexillum/v0.1.0/scripts/install.sh | bash
```
  </CodeBlockTab>
</CodeBlockTabs>

Este script:

1. Detecta tu sistema operativo y arquitectura;
2. Usa Homebrew si `brew` está en tu PATH (`brew install isaias-alt/tap/vexillum`, o `brew upgrade` cuando la fórmula ya está instalada);
3. Si no, descarga el archivo del release para tu plataforma y **verifica su checksum sha256** contra el `checksums.txt` del release, y se niega a instalar si no coincide;
4. Instala el binario en `/usr/local/bin`, o en `~/.local/bin` cuando no podés escribir en `/usr/local/bin` (avisa si ese directorio no está en tu PATH);
5. Comprueba que ahora existe un `vx` que funciona (en el directorio de instalación, el prefijo de Homebrew o tu PATH) y termina con un error si no.

Sin opciones instala el último release **stable** y nunca un pre-release. Para probar un build canary o instalar una versión exacta, pasá `--channel canary` o `--version <tag>`; las dos son descargas directas que se saltean Homebrew. Ver [Canales de release](/es/docs/get-started/release-channels).

Comprobá que funcionó:

```bash
vx --version
```

Para actualizar el binario más adelante, corré `vx upgrade`. Ver [Actualización](/es/docs/get-started/upgrading).

## Instalá lo que vexillum orquesta

vexillum no instala sus herramientas; las verifica.

| Herramienta | Para qué | Requerida |
| --- | --- | --- |
| [Claude Code](https://claude.com/claude-code) | el commander y cada soldier | sí |
| [herdr](https://herdr.dev) | los panes donde corren los soldiers | sí |
| `gh` (GitHub CLI) | `vx ship`, y aterrizar un PR enviado | solo para eso |

Corré la verificación cuando quieras:

```bash
vx doctor
```

`doctor` es de solo lectura. Imprime `[ok]` o `[missing]` por cada herramienta, la versión de herdr, `~/.vexillum/`, si el proyecto actual está inicializado y es un repositorio git, y, para un proyecto inicializado, el estado del [bloque de vexillum](/es/docs/concepts/agents-md-slot) en `AGENTS.md` o `CLAUDE.md`, si `CLAUDE.md` importa `AGENTS.md` (cuando el bloque está en `AGENTS.md`), cada [skill](/es/docs/concepts/skills), si [`models.json`](/es/docs/reference/models-json) es válido, y el hook `Stop` del sentinel: si está registrado, si [encuentra vx desde un entorno mínimo](/es/docs/concepts/sentinel#el-hook-no-depende-de-tu-path) y si hay un sentinel corriendo:

```text
[ok] AGENTS.md vexillum block - current (en)
[ok] CLAUDE.md imports AGENTS.md
[ok] skill vexillum - installed, current
[ok] models.json - valid, 5 profiles
[ok] sentinel Stop hook - registered in .claude/settings.json
[ok] sentinel Stop hook finds vx - found with a minimal environment
[ok] sentinel - running, 1 Stop hook await(s) waiting
```

Sale con código distinto de cero cuando falla un chequeo requerido. Un hook `Stop` que no encuentra vx es un `[warn]` con el arreglo, nunca un fallo.

## Solución de problemas: cuarentena en macOS

Un tarball descargado en el navegador y extraído con doble clic recibe un atributo de cuarentena, y la primera ejecución puede quedar bloqueada ("no se puede verificar el desarrollador"). Quitalo con:

```bash
xattr -d com.apple.quarantine "$(command -v vx)"
```

Homebrew y el instalador de curl no tienen este problema.
