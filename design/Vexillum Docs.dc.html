COMMANDS / DISPATCH
vx dispatch
Sends a soldier into its own camp to work a task. Every soldier runs independently — the commander tracks it, the sentinel watches it, and you get notified only when it needs you.
usage
vx dispatch <task> --kind <mission|scout> [--model <name>]
Arguments
{{ a.name }}
{{ a.desc }}
Example
$ vx dispatch "refactor the payment module" --kind mission --model sonnet
↳ dispatched · camp/refactor-payment-module
↳ soldier running · sentinel watching
Note — a scout never writes to its camp; use it to investigate before committing a mission.
