## Two different files

- **vexillum's own `AGENTS.md`** (in the vexillum repository) governs how vexillum itself is built. It is not what you get.
- **`.claude/rules/vexillum.md`** is the *product* rules file. `vx init` scaffolds it into your project. Claude Code loads it every session, unconditionally - alongside whatever `AGENTS.md` or `CLAUDE.md` the project already has, which vexillum never touches.

This is the product's central design decision: the commander's intelligence is markdown, the binary is plumbing.

## What the rules cover

| Section | Subject |
| --- | --- |
| Role check | The rules apply only to the commander. A soldier reading them by accident must follow its dispatch prompt instead, and never dispatch further soldiers. |
| Vocabulary, Authority | The terms; an explicit instruction from you overrides a rule, but the commander must say which rule it set aside. |
| Tone | How to address you and when to drop the flavor (bad news is reported plainly). |
| The sentinel | What the `Stop` hook means and how to react to `interrupted`. |
| Dispatching a soldier | Always `vx dispatch`, never the commander's own subagent tool. |
| Choosing a model and effort | The decision table below. |
| Landing, Shipping, Releasing | Ask before landing; release right after. |

### Choosing a model and effort

The first matching rule wins. vexillum validates the values but never picks them.

| # | Situation | Model and effort |
| --- | --- | --- |
| 1 | Scout whose question is verifiable facts from an authoritative source | `haiku`, `low` |
| 2 | Scout that needs judgment | `sonnet`, `medium` |
| 3 | Mission that is a trivial mechanical edit | `haiku`, `low` |
| 4 | Big or ambiguous multi-file mission, risky refactor | `sonnet`, `high` |
| 5 | You explicitly ask for Opus | `opus`, `high` |
| 6 | Nothing above fits | `sonnet`, `medium` |

## Editing and upgrading

The file is yours to edit: tune the table, the tone, the landing posture. `init` writes it once and never overwrites it; [`upgrade`](/docs/get-started/upgrading) refreshes it only when it is unmodified, or with `--force`.

`vx init --global` writes the rules to `~/.claude/rules/vexillum.md` instead, applying the commander persona to every Claude Code session on the machine. It is opt-in for that reason.
