`muster` es un Agent Skill de Claude Code que viene dentro del binario de vexillum. Lee `vx status --json` y agrupa las tareas del proyecto para que veas de un vistazo qué te necesita.

## Instalación

`vx init` ofrece instalarlo junto con las otras [skills](/es/docs/concepts/skills) (en `.claude/skills/muster/`), y `vx upgrade --skills` lo instala después. No interviene Node ni `npx`. `vx doctor` informa `skill muster - installed, current`. El texto completo está en [Skill: muster](/es/docs/reference/skills/muster).

## Uso

| Comando | Resultado |
| --- | --- |
| `/muster` | la tropa completa, abierta como un tablero interactivo |
| `/muster pr` | missions con un PR real de GitHub, enriquecidas con el estado en vivo del PR |
| `/muster sitrep` | un resumen solo en terminal de los dispatches de esta sesión; nunca abre un tablero |

El tablero tiene cinco secciones: **Needs attention** (blocked, interrupted, failed), **Awaiting land approval** (missions done todavía no aterrizadas), **In flight**, **Finished** y **Shipped**. Una tarea blocked muestra su pregunta en el tablero.

muster es de solo lectura: nunca aterriza, hace release ni re-despacha nada. Nunca infiere un status que vexillum no reportó, y clasifica "aterrizada" con git, ya que vexillum no registra el landing en la tarea.
